iperf3 settings

Choose one or more network protocols. Each selection appears as a separate result in the final report.

All tests use a private peer VM. iperf3 uses TCP for its control connection and the selected protocol for benchmark traffic.

Phoronix settings

Choose one or more curated OpenBenchmarking profiles. Each profile runs with a fixed configuration and appears as a separate result in the final report.

Profiles are pinned and limited to tests validated for both x86_64 and AArch64 Oracle Linux instances.

DeathStarBench settings

The selected microservices workload runs with native Podman and podman-compose. A separate fixed-size OCI VM generates load against the benchmark VM's private address.

Connections and request rate must each be at least—and evenly divisible by—the number of worker threads. The benchmark shape requires at least 16 GB of memory.

ApacheBench settings

Choose one or both HTTP connection modes. Each mode is measured independently and appears as a separate result in the final report.

The benchmark VM serves fixed-size responses while a separate VM runs Apache HTTP Server Benchmarking Tool traffic over the private VCN. Concurrency cannot exceed the measured request count.
