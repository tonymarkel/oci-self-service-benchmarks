GCP /data volumes use pd-balanced by default; C4A uses Hyperdisk Balanced. Select a machine type to see the exact disk and network profile. These provider-required settings are recorded in the report.

Phoronix settings

Choose one or more curated OpenBenchmarking profiles. Each profile runs with a fixed configuration and appears as a separate result in the final report.

Profiles are pinned and limited to tests validated for both x86_64 and AArch64 Oracle Linux instances.

DeathStarBench settings

The selected microservices workload runs with native Podman and podman-compose. A separate fixed-size x86 load-generator VM sends traffic to the benchmark VM's private cloud-network address.

Connections and request rate must each be at least—and evenly divisible by—the number of worker threads. The benchmark shape requires at least 16 GB of memory.

ApacheBench settings

Choose one or both HTTP connection modes. Each mode is measured independently and appears as a separate result in the final report.

The benchmark VM serves fixed-size responses while a separate fixed-size x86 load-generator VM runs Apache HTTP Server Benchmarking Tool traffic over the private cloud network. Concurrency cannot exceed the measured request count.
